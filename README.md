# MagFlow

<h2 id="english">English</h2>

MagFlow is a Python/Jupyter-based workflow for parsing, filtering, and visualizing Aidu (China) magnetometer survey data. It automates `.DAT` file conversion, bounds checks coordinates, and generates interactive 2D/3D contour plots.

### Project Structure
- `data/raw/`: Place your raw Aidu `.DAT` files here.
- `data/processed/`: Autogenerated, merged data (`magmeter_data.csv`).
- `data/boundaries/`: Parcel boundaries (`plots_coordination.csv`).
- `main.ipynb`: The core pipeline notebook.

### Requirements
This project uses Python 3 and requires several data science packages (`pandas`, `numpy`, `plotly`, `scipy`, `shapely`, `chardet`, `jupyter`). 

We highly recommend using an isolated virtual environment (`.venv`) to run this project.

### Step-by-Step Installation

1. **Navigate to the core directory**  
   Open your terminal and ensure you are in the project folder.

2. **Set up a Virtual Environment**  
   Avoid global package conflicts by creating a local `.venv`:  
   ```bash
   python3 -m venv .venv
   ```

3. **Activate the Virtual Environment**  
   Before running scripts or installing, activate the environment:  
   - On **macOS/Linux**: `source .venv/bin/activate`
   - On **Windows**: `.venv\Scripts\activate`

4. **Install Dependencies**  
   Install all necessary tools using the provided requirements file:  
   ```bash
   pip install -r requirements.txt
   ```

### Usage Workflow

1. **Add Data**: Ensure your input files (`*.DAT`) are copied into the `data/raw/` directory.
2. **Define Boundaries**: Check/update your target polygon coordinates in `data/boundaries/plots_coordination.csv`.
3. **Launch Jupyter**: With your virtual environment active, run Jupyter:
   ```bash
   jupyter notebook main.ipynb
   ```
4. **Execute**: Run all cells sequentially in the notebook. 
   - Step 1 consolidates raw data to `data/processed/magmeter_data.csv`. 
   - Step 2 visualizes your magnetic anomalies interactively.

<h2 id="中文">中文</h2>

MagFlow 是一个基于 Python 和 Jupyter 的工作流，用于解析、过滤和可视化爱迪（中国）磁力仪的测量数据。它能自动转换 `.DAT` 文件，进行边界的地理坐标检查，并生成交互式的 2D/3D 等高线图。

### 项目结构
- `data/raw/`：在此处放置您的原始爱迪 `.DAT` 数据文件。
- `data/processed/`：自动生成并合并的数据保留于此（`magmeter_data.csv`）。
- `data/boundaries/`：区块边界的定义文件（`plots_coordination.csv`）。
- `main.ipynb`：执行数据处理核心流程的 Jupyter Notebook。

### 环境要求
本项目使用 Python 3，并依赖多个数据科学工具包（`pandas`、`numpy`、`plotly`、`scipy`、`shapely`、`chardet`、`jupyter`）。

我们强烈建议使用独立的虚拟环境（`.venv`）来运行此项目。

### 逐步安装指南

1. **导航至核心目录**  
   打开您的终端端点工具，并确保当前位于该项目文件夹中。

2. **设置虚拟环境**  
   创建本地的 `.venv` 虚拟环境以避免全局包冲突：
   ```bash
   python3 -m venv .venv
   ```

3. **激活虚拟环境**  
   在运行任何脚本或安装工具之前，请先激活该环境：
   - 在 **macOS 或 Linux** 系统下：`source .venv/bin/activate`
   - 在 **Windows** 系统下：`.venv\Scripts\activate`

4. **安装依赖项**  
   使用我们提供的需求文件来安装所有必要的依赖工具：
   ```bash
   pip install -r requirements.txt
   ```

### 使用工作流

1. **添加数据**：确保您的磁力仪输入文件（`*.DAT`）已放入 `data/raw/` 目录中。
2. **定义边界**：在 `data/boundaries/plots_coordination.csv` 中检查或更新您的目标多边形边界坐标。
3. **启动 Jupyter**：在激活虚拟环境后，通过终端运行 Jupyter：
   ```bash
   jupyter notebook main.ipynb
   ```
4. **运行代码**：依次在笔记本中运行所有代码单元格。
   - 第 1 步：系统会将原始数据重新整理并转换为 `data/processed/magmeter_data.csv` 标准文件。
   - 第 2 步：提取出位于所选地块边界内区域的地磁异常指标，并生成直观的高级可视化地图。
